CADView HTML 도면 뷰어 & 단일 파일 공유 가이드

다른 사람에게 HTML 파일 하나만 줘서 바로 보게 하는 방법 (추천!)
  1. 좌측 상단 [도면 열기 (.DWG/.DXF)] 버튼으로 내 컴퓨터의 도면 파일을 엽니다.
  2. 필요하면 거리/면적 측정이나 주석 메모를 도면 위에 표시합니다.
  3. 우측 상단 초록색 [공유용 단일 HTML 저장] 버튼을 클릭합니다.
  4. 생성된 *_viewer.html 파일을 카카오톡, 이메일, 메신저로 상대방에게 전달하면, 상대방은 AutoCAD나 원본 DWG 파일 없이 크롬/엣지 브라우저로 더블클릭만 해도 즉시 도면을 확대/축소/측정할 수 있습니다!
🖱️ 마우스 & 단축키 조작
  • • 마우스 휠: 커서 위치 기준 확대/축소
  • • 드래그 / 휠 클릭 드래그: 화면 이동 (Pan)
  • • 더블 클릭 / F 키: 도면 전체 화면 맞춤
  • • D / A 키: 거리 측정 / 면적 측정
  • • S / G 키: 객체 스냅(OSNAP) / 그리드 토글
  • • ESC 키: 현재 측정/선택 취소
📂 지원 파일 포맷
  • • .DWG: LibreDWG WebAssembly 엔진을 통해 브라우저에서 직접 바이너리 해독 (R14 ~ AutoCAD 2018+)
  • • .DXF: 내장 네이티브 파서로 인터넷 연결 없이도 100% 오프라인 즉시 렌더링
  • • 외부 유출 제로: 모든 도면 파일은 서버 업로드 없이 브라우저 메모리에서만 처리됩니다.
